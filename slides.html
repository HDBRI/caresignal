CareSignal

Turns a family caregiver's everyday notes into an evidence-linked, caregiver-reviewed handoff — while urgent safety guidance never depends on AI.

Classroom prototype · synthetic data only · not medical advice · not clinically validated · not HIPAA compliant · receiver is simulated · in an emergency, call 911.

Problem: home observations don't reach the care team well

  • ~63 million U.S. family caregivers (1 in 4 adults); only 22% report training for the care tasks they do [AARP & NAC, 2025]
  • Handoffs have been linked to adverse clinical events; clinicians use structured formats like I-PASS / SBAR [AHRQ PSNet]
  • Caregivers have no equivalent: notes live in memory, texts, journals, trackers and portal messages
The risk with AI summaries: a polished summary can hide uncertainty, invent facts, or sit between a caregiver and urgent action.

We did not measure caregivers' time or frustration — no user research was done.

New = the combination: exact-quote evidence gate on every AI statement · conflicts and "not reported" kept · rule-based urgent guidance before any AI · caregiver-approved, frozen snapshot (SHA-256) before delivery. Among the tools checked, none described this combination — not a "first" claim. Sources accessed 2026-10-26.

Architecture: a sequential pipeline, not multi-agent

No autonomous agents: application code decides every next step; the model never calls tools or other models.
  • Model: gpt-6-luna via the course Portkey key (the only allowed model); JSON mode; capped output.
  • If AI fails (no key, timeout, bad output): stored as failed; notes, charts and safety rules keep working; handoff lists notes as written.
  • Nothing from the model is shown or stored before validation.

One real run, end to end real app synthetic note

  1. Note saved as OBS-0001, exactly as written; safety rules ran — none matched
  2. AI category (gpt-6-luna-2026-09-22): Sleep, nutrition and hydration; 2 facts, each an exact quote — 415 in / 164 out tokens
  3. Weekly handoff HO-F3N25BAH drafted; every line cites notes (e.g. OBS-C1-02, OBS-0001) — 1,209 in / 3,139 out tokens, 17.7 s
  4. Caregiver approves after "I have read this draft…" — exact text frozen with SHA-256
  5. POST /api/handoffs → 201, receipt RC-6JE3KQY5VA returned only after the server saved it
  6. Acknowledged by a separate click in the simulated receiver; then the fictional outcome

First attempt: the AI summary timed out (20 s limit ×2) → the draft honestly listed notes "as written". Limit raised to 60 s; second attempt above succeeded.

Limits and next steps

Limits today

  • Small predefined safety rule set; not triage
  • Synthetic data only; no clinical validation
  • No EHR or real care team; receiver simulated
  • Needs the AI API (notes & safety rules work without it)
  • Model errors remain; small set, one live run; no user research; price unverified

Next (proposed, not built)

  • Consented usability study: time to handoff, key facts kept
  • Clinician review of rules and handoff format
  • Repeated runs + independent labels
  • Real delivery path only after privacy review
